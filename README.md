# My HTML Docker Project

Simple HTML website running with Docker and Nginx.

## Run locally

Build image:

docker build -t my-html-project .

Run container:

docker run -d -p 8080:80 my-html-project

Open browser:

http://localhost:8080


## Docker Hub

Image:

docker pull alaayubb/my-html-project
